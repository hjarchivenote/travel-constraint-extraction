# Data

Planned home for the custom travel change-request dataset, finalized annotation guidelines, provenance records, and scenario-based train/validation/test splits.

**Current status:** no completed dataset is published. The initial target is approximately 400 examples in total, starting with a 30–50-example pilot. Reference itineraries will be set in London.

Only completed, reviewed artifacts will be published here. Before collection, finalize the output schema and annotation rules, including the treatment of weather-dependent requests. Record any AI assistance, manually verify targets, and keep each scenario and its paraphrases in the same split. Define a dataset license before release for reuse.

The NLP dataset consists of custom requests and target annotations. London place information and weather-forecast records are supporting demonstration data and will be documented with their own sources and applicable terms when used.
